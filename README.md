# impostersyndrome
This artwork is about imposter syndrome and has a parallax effect.

The artwork and the first version of the code are entirely my own work. That original version is
saved as the release **v1-original**.

Later I made it smoother with help from Claude (AI):

- Each layer is cropped to its visible area and saved as WebP (about 95 MB down to 5 MB)
- A small custom scroll script replaces Rellax, so layers move relative to the artwork's size
- Layers are clipped to the artwork, so nothing slides out of the frame
- On phones the artwork stays centered while the layers move
